# 학술제 전자제품 쇼핑몰 웹페이지

[사이트 열기](https://shop.pigs0516.com/) · [배포·자동 업데이트·복구 안내](docs/deployment.md)

AWS의 전용 nginx 컨테이너에서 제공하는 학술제 데모입니다. 실제 회원 인증·주문 저장·결제·DB는 없습니다. `shop-aws` 전용 Cloudflare 터널이 기존 `127.0.0.1:3501` 원본을 연결합니다. `main` PR 병합 → 보안·이미지 CI → 제한된 이벤트 배포 명령으로 이 사이트만 교체합니다. 배포 polling timer는 해제했고 백업 작업은 유지합니다. 초기 승격과 GitHub 수동 배포는 확인했으며, 이후 새 PR의 자동 신규 배포는 아직 검증 전입니다. [이벤트 배포 상태](docs/event-deployment.md)를 확인합니다.

학술제 발표를 위해 제작한 정적 전자제품 쇼핑몰 웹사이트입니다.

스마트폰, 태블릿, 노트북 상품 상세 페이지와 구매 페이지, 장바구니 계산 UI를 HTML/CSS/JavaScript로 구현했습니다.

## 소스 검토 기준

이 README는 저장소의 HTML 100개 이상, `10-11.css`, `10-11.js`, 상품 이미지 파일 구성을 기준으로 다시 작성했습니다. 서버 코드, DB, 실제 결제 API는 저장소에서 확인되지 않았기 때문에 정적 웹 프로토타입으로 명확히 설명합니다. 이미지 바이너리 내용은 열람 대신 파일 구성과 페이지 참조 기준으로 확인했습니다.

검토 결과 이 프로젝트는 Apple/Samsung/Xiaomi 전자제품 쇼핑몰을 HTML 페이지 단위로 직접 구성한 학술제용 정적 웹사이트입니다. 메인, 카테고리, 브랜드별 목록, 상세 상품, 구매창, 장바구니, 로그인/회원가입, 고객문의 페이지가 분리되어 있고, 장바구니 계산과 간단한 팝업 동작은 공통 JavaScript로 처리합니다.

## 처음 검토할 때 볼 순서

1. `메인.html`에서 전체 사이트 진입과 브랜드/카테고리 흐름을 확인합니다.
2. `카테고리.html`에서 브랜드별 상품 목록으로 이동하는 구조를 봅니다.
3. 브랜드별 시리즈 HTML과 개별 상품 HTML을 열어 상품 상세 구성을 확인합니다.
4. `장바구니.html`, `결제창.html`, `10-11.js`를 함께 보면 장바구니 계산과 결제 프로토타입 흐름을 볼 수 있습니다.
5. 서버 연동이 없는 정적 프로젝트이므로, 실제 주문 저장/결제 승인/회원 인증은 구현 범위 밖이라는 점을 확인합니다.

## 사이트 사용 흐름

1. `메인.html`에서 쇼핑몰 첫 화면을 확인합니다.
2. `카테고리.html` 또는 브랜드/제품군 페이지에서 상품을 선택합니다.
3. 상품 상세 페이지에서 이미지와 제품 정보를 확인합니다.
4. `구매창.html` 또는 상품별 구매 페이지에서 구매 화면을 확인합니다.
5. `장바구니.html`에서 수량 변경, 선택 삭제, 전체 삭제, 합계 계산을 확인합니다.
6. `로그인.html`, `회원가입.html`, `고객문의.html`에서 보조 페이지 흐름을 확인합니다.

## 실행 방법

별도 빌드 과정이 없는 정적 웹사이트입니다.

브라우저에서 원하는 HTML 파일을 직접 열면 됩니다. 처음 확인할 때는 `메인.html`을 여는 것을 권장합니다.

로컬 서버로 확인하고 싶을 때:

```bash
python -m http.server 5500
```

접속 주소:

```text
http://localhost:5500
```

GitHub Pages에 올릴 때는 `index.html`이 없으면 기본 진입점을 자동으로 잡기 어렵습니다. Pages 배포를 목표로 한다면 `메인.html`을 `index.html`로 복사하거나, 별도 `index.html`에서 `메인.html`로 이동시키는 진입 파일을 추가하는 것이 좋습니다.

## 구현 포인트

- 순수 JavaScript 객체로 장바구니 상태와 UI 업데이트 함수를 관리했습니다.
- 체크된 상품만 합계에 반영하고, 수량 변경 시 개별 합계와 전체 합계를 함께 갱신합니다.
- 제품 상세 페이지와 구매 페이지를 상품별 HTML로 분리해 학술제 발표 시 화면 전환을 단순하게 구성했습니다.

## 확인 포인트

- 장바구니에서 수량 증가/감소 시 개별 금액과 전체 금액이 같이 바뀌는지 확인합니다.
- 체크 해제한 상품이 합계에서 제외되는지 확인합니다.
- 선택 삭제와 전체 삭제 후 상품 개수와 금액이 초기화되는지 확인합니다.
- 상품 상세 페이지에서 구매 페이지로 이동하는 링크가 깨지지 않는지 확인합니다.
- 이미지 파일명에 공백과 한글이 많으므로 경로 대소문자와 파일명을 그대로 유지합니다.

## 개선 방향

- `index.html` 대표 진입점 추가
- 상품 데이터를 JSON으로 분리
- 반복되는 상품 HTML을 템플릿화
- 반응형 레이아웃 정리
- 이미지 출처와 라이선스 정리

- 이미지 파일은 공개 가능한 출처인지 확인한 뒤 업로드합니다.
