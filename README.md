# 학술제 전자제품 쇼핑몰 웹페이지

학술제 발표를 위해 제작한 정적 전자제품 쇼핑몰 웹사이트입니다.

스마트폰, 태블릿, 노트북 상품 상세 페이지와 구매 페이지, 장바구니 계산 UI를 HTML/CSS/JavaScript로 구현했습니다.

## 주요 기능

- 제품별 상세 페이지
- 제품 구매 페이지
- 장바구니 수량 변경
- 선택 상품 삭제와 전체 삭제
- 상품 개수와 합계 금액 재계산
- 고객 문의, 장바구니, 로그인 팝업 연결
- Apple, Samsung, Xiaomi 계열 상품 이미지 구성

## 기술 스택

- HTML
- CSS
- JavaScript
- 정적 이미지 자산

## 프로젝트 구조

```text
학술제 대회/
  *.html          상품 상세, 구매, 로그인, 고객 문의, 장바구니 페이지
  10-11.css       공통 장바구니/구매 UI 스타일
  10-11.js        장바구니 수량/합계 계산 로직
  image/          제품 이미지 자산
```

## 실행 방법

별도 빌드 과정이 없는 정적 웹사이트입니다.

브라우저에서 원하는 HTML 파일을 직접 열면 됩니다. 메인 진입 페이지가 여러 개라면 대표 상품 페이지나 메인 HTML을 GitHub Pages의 시작점으로 지정합니다.

로컬 서버로 확인하고 싶을 때:

```bash
python -m http.server 5500
```

접속 주소:

```text
http://localhost:5500
```

## 구현 포인트

- 순수 JavaScript 객체로 장바구니 상태와 UI 업데이트 함수를 관리했습니다.
- 체크된 상품만 합계에 반영하고, 수량 변경 시 개별 합계와 전체 합계를 함께 갱신합니다.
- 제품 상세 페이지와 구매 페이지를 상품별 HTML로 분리해 학술제 발표 시 화면 전환을 단순하게 구성했습니다.

## 개선 방향

- `index.html` 대표 진입점 추가
- 상품 데이터를 JSON으로 분리
- 반복되는 상품 HTML을 템플릿화
- 반응형 레이아웃 정리
- 이미지 출처와 라이선스 정리

## GitHub 업로드 전 주의

- `.vscode`, `.DS_Store` 같은 로컬 설정 파일은 제외합니다.
- 이미지 파일은 공개 가능한 출처인지 확인한 뒤 업로드합니다.
